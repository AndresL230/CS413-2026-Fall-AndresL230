LAMBDA workbench

Check and run small programs written in the LAMBDA language. Everything runs on this computer.

  1. Load a program or type one.
  2. Apply it, so the tools use that exact text.
  3. Run a tool on it.
  4. Read the result below.

1 Source

Choose where the program comes from, then press Load. Loading replaces the current source and starts a new revision.

Choose File…
Opens a text file from this computer. The file itself is never changed.
Manual input
Clears the editor so you can type a program from scratch.
Factorial, Fibonacci
Ready-made examples you can run or edit.

The applied source is the text the tools run on. The revision number goes up each time it changes, and every result says which revision it came from.

2 Editor

A program is one constructor expression, for example D0Eop2("+", D0Eint(20), D0Eint(22)). It may span several lines, and lines starting with # are comments. The limit is 64 KiB.

Apply changes
Makes the editor text the new applied source and clears earlier results. Empty text is rejected.
Discard changes
Throws away your edits and shows the applied source again.

While the editor has unapplied changes, the tools and the Load menu are turned off, so a result can never refer to text you have not applied.

3 Actions

Each tool runs on the applied source. A run is stopped automatically if it takes too long, and the source is kept.

    4 Results

    Status

    Newest first. Each result names the tool, the revision it ran on and the outcome. Results are cleared whenever the source changes.
